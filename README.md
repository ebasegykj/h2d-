预览见
https://ksh.hehyc.com
就是一个方便硬件工程师做数据可视化的
基于浏览器使用不用安装

可以下载保存本地使用
------------------------------------
直接下载 数据可视化v37.html 和lib文件夹 放在一起 浏览器打开即可使用
-----------------------------------

比如串口数据的可视化，
16进制转10进制，
1,2,3,4任意字节，
数据任意序号的组合，
原始数据是无换行符时，导入数据会提示需要整理数据的个数
原始数据是整理好的则没有提示。
比如下面数据输入3后会自动整理成
eb9001eb9002eb9003eb9004...
____________________________________
eb 90 01

eb 90 02

eb 90 03

..。
_____________________________________
绘图就会按填入的索引号按列绘图了。
